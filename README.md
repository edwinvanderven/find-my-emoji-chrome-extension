# Emoji Finder Chrome Extension

## Overview

The **Emoji Finder** Chrome extension allows users to quickly find emojis by typing in a keyword. This lightweight and efficient extension enhances user experience by making emoji discovery seamless and intuitive.

## Features

- 🔍 Search for emojis using keywords
- 📋 Click to copy an emoji to the clipboard
- ⚡ Fast and responsive UI
- 🌐 Works offline with no external API dependencies

## Installation

### From the Chrome Web Store

1. Visit the [Chrome Web Store](https://chromewebstore.google.com/detail/find-my-emoji/kgalfcfddkkkeiiaaijehcockebphkgc)
2. Click **Add to Chrome**.
3. Pin the extension for easy access.

### Manual Installation (Developer Mode)

1. Clone the repository:

   ```bash
   git clone https://github.com/edwinvanderven/find-my-emoji-chrome-extension.git
   cd find-my-emoji-chrome-extension
   ```

2. Open **chrome://extensions/** in your Chrome browser.
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** and select the cloned repository folder.
5. The extension will now be available in Chrome!

## Usage

1. Click the extension icon in the Chrome toolbar.
2. Type a keyword (e.g., `smile`, `heart`, `fire`).
3. Select an emoji to copy it to your clipboard.
4. Paste the emoji anywhere you need!

## Development

### Running Locally

To modify and test the extension locally:

1. Make your changes in the source files.
2. Reload the extension in **chrome://extensions/**.
3. Test in Chrome.
